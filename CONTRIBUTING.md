# Contributing

Thanks for your interest in the Semperr website.

This repository powers the production marketing site and blog for
[Semperr](https://www.semperr.com). It is maintained by the Semperr team and
is not seeking general open-source contributions, but bug reports and
suggestions are welcome.

## Reporting issues

- Open an issue describing the problem, the page URL, and steps to reproduce.
- For content corrections (typos, outdated info), an issue is enough — no PR needed.

## Pull requests

- Open an issue first so we can confirm the change is wanted.
- Keep PRs small and focused.
- Run `npm run build` locally and confirm it passes before submitting.

## Development setup

```bash
npm install
npm run dev
```

Blog posts live in `src/app/blog/posts/` as `.mdx` files.
